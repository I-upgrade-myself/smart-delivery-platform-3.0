# Smart Delivery Platform 3.0

## Опис
Це монорепозиторій для платформи Smart Delivery. Проєкт реалізується за принципами мікросервісної архітектури.

## Стек технологій
- **Backend:** Java 21, Spring Boot, Spring Cloud, Maven
- **Frontend:** React + TypeScript (плани)
- **База даних:** PostgreSQL
- **Messaging:** Kafka (MSK)
- **Інфраструктура:** Docker, Terraform, Helm
- **CI/CD:** GitHub Actions
- **Моніторинг:** Prometheus, Grafana, Micrometer
- **Документація:** ADRs, OpenAPI
